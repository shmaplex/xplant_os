One call completes the current stage and makes the new one current. `stage` is required; give exactly one of `plant_id` or `explant_id`.

> **Full schema coming soon.** The complete request and response schema for this endpoint is being published. The example below shows a typical call.

## Example

```bash tab="curl" tab-group="lang"
curl -X POST https://app.xplantpro.com/api/v1/stages \
  -H "Authorization: Bearer $XPLANT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "plant_id": "0b8e2f4c-6a1d-4c3e-9f7a-2d5b8c1e4a90",
    "stage": "Multiplication"
  }'
```

`200` with `{ "ok": true, "data": … }`. `data` holds the result.
