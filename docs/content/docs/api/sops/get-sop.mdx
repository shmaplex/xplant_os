You get the version the lab works from right now, never a draft and never a version that is approved but not yet in force. If no version is in force, `version` is `null` and there are no steps; handle that rather than treating it as an empty procedure.

`currentVersion` (the highest version that exists) and `version.version` (the one in force) can differ, and often do.

## Response

`200` with `{ "ok": true, "data": … }`. `data` holds the result.

## Errors
